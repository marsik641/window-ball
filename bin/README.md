# Готовая программа

Сюда [скрипт сборки](../scripts/build.ps1) записывает `WindowBall.exe` и копирует `WindowBall.exe.config`. Для запуска из исходников открой `WindowBall.exe` в этой папке.

Во время работы рядом появляются `WindowBall.settings.json` с настройками и рекордами, а при ошибке — `error.log`. Пересборка не перезаписывает пользовательские настройки. Перед пересборкой закрой запущенную программу.

В Git хранится только этот README. Исполняемый файл, конфигурация сборки и локальные данные исключены через `.gitignore`. Для передачи программы используй архив из [dist](../dist/README.md).
