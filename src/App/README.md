# Приложение и управление

- `Program.cs` — точка входа, служебные команды, основной прозрачный `BallForm`, мышь, таймер и реакции на изменение экрана.
- `BallGames.cs` — вторая часть `BallForm`: переключение скинов, старт и остановка игры, меню, игровые панели и сохранение рекордов.
- `Settings.cs` — загрузка и сохранение размера, скина, физических настроек и рекордов в `WindowBall.settings.json` рядом с исполняемым файлом.

Расчёт движения делегирован в [Physics](../Physics/README.md), игровые правила — в [Games](../Games/README.md), отрисовка — в [Graphics](../Graphics/README.md).
