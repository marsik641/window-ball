# Игровые правила

`SportsGame.cs` содержит состояние раунда, счёт, таймер, мишени, зачёт бросков и условия завершения:

- теннис — попадания после отскока;
- баскетбол — серия контролируемых отскоков об пол;
- американский футбол — прямые пасы в движущуюся зону;
- сокс — подбивания без касания пола.

Здесь нет окон и обработки мыши. Эти правила вызывает [App/BallGames.cs](../App/BallGames.cs), а игровой счёт и мишени рисует [Graphics/GameOverlay.cs](../Graphics/GameOverlay.cs).
