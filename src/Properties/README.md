# Метаданные приложения

`AssemblyInfo.cs` задаёт название, автора, версию сборки, файловую версию и пользовательскую версию `Window Ball`.

Перед выпуском синхронно обновляй три атрибута версии, [историю изменений](../../docs/CHANGELOG.md) и текст в [docs/releases](../../docs/releases/README.md). Скрипт упаковки определяет имя архива по версии собранного `.exe`.

Манифест Windows и конфигурация .NET находятся в [packaging](../../packaging/README.md).
