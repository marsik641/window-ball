# Исходный код

Код приложения на C# с общим пространством имён `WindowBall`. Расположение файлов по подпапкам разделяет обязанности; дополнительных проектов и пакетов нет.

| Папка | Назначение |
| --- | --- |
| [App](App/README.md) | Запуск, окно мяча, управление и настройки |
| [Physics](Physics/README.md) | Движение, контакты, материалы и оценка броска |
| [Games](Games/README.md) | Цели, счёт и правила четырёх игр |
| [Graphics](Graphics/README.md) | Текстуры, игровые панели и прозрачные окна Windows |
| [Properties](Properties/README.md) | Версия и сведения о приложении |

Все `.cs` из этой папки автоматически подхватывает [скрипт сборки](../scripts/build.ps1). Проверки находятся отдельно в [tests](../tests/README.md).
