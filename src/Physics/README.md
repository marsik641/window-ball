# Физика

- `BallPhysics.cs` — движение с фиксированным шагом, гравитация, сопротивление воздуха, столкновения круга или повёрнутого эллипса с границами, трение, вращение и переход в покой. В этом же файле находится `ThrowTracker`, который оценивает скорость движения мыши перед отпусканием.
- `BallProfile.cs` — четыре материала и их параметры: масса, упругость, трение, сопротивление, момент инерции и форма. Здесь же перечислены скины `BallSkin`.

Параметры, источники и упрощения модели описаны в [docs/PHYSICS.md](../../docs/PHYSICS.md). Проверки материалов и контактов находятся в [tests/SelfTests.cs](../../tests/SelfTests.cs).
