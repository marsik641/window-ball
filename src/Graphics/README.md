# Графика и окна Windows

- `BallArt.cs` — процедурная отрисовка четырёх мячей с освещением, фактурой и прозрачным фоном.
- `Native.cs` — вызовы Win32, DPI, точность таймера и `SpriteSet`: кеш вращающихся кадров и передача изображения в прозрачное окно.
- `GameOverlay.cs` — прозрачные панели счёта и мишеней, пропускающие клики, а также `GameArt` для их отрисовки и галереи скинов.

Готовые изображения для README и иконка лежат в [assets](../../assets/README.md). Физическая форма тел рассчитывается в [Physics](../Physics/README.md).
