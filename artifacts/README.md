# Отчёты и служебные изображения

- `test-results.txt` — результат проверок физики и игровых правил при сборке с `-Test`.
- `smoke-results.txt` — результат проверки настоящих окон при сборке с `-SmokeTest`.
- Изображения предпросмотра и прочие материалы проверки, например `hud-preview.png`.

Эти файлы создаются локально и не входят в релиз. В Git хранится только этот README. Скрипты сборки и CI используют эту папку для отчётов, чтобы не засорять корень.
