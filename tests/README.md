# Проверки

`SelfTests.cs` содержит две группы проверок без внешнего тестового фреймворка:

- `SelfTests` — физика, материалы, броски, прозрачность изображений, игровые правила, таймеры и рекорды;
- `SmokeTests` — настоящее окно приложения, анимация, захват мыши, смена скинов и размеров, пауза, счёт и окна мишеней.

Из корня репозитория:

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File .\scripts\build.ps1 -Test -SmokeTest
```

Отчёты записываются в [artifacts](../artifacts/README.md). Smoke-проверка на несколько секунд показывает окна мяча и игры.

Этот файл компилируется вместе с приложением: его проверки доступны через служебные аргументы `--self-test` и `--smoke-test`. Для запуска готовой программы тестовые исходники не нужны.
