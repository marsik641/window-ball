# Файлы для сборки и переносимого выпуска

- `app.manifest` — манифест Windows: запуск без прав администратора, поддержка Windows 10/11 и DPI.
- `WindowBall.exe.config` — выбор .NET Framework 4.8; сборщик копирует этот файл рядом с готовым `.exe` в `bin/`.
- `Запустить.cmd` — запускатель для распакованного релиза. Он ожидает `WindowBall.exe` в той же папке.
- `PORTABLE.md` — шаблон README внутри переносимого архива. Упаковщик заменяет `{{VERSION}}` на версию приложения и сохраняет результат как `README.md`.

Здесь хранятся исходные файлы упаковки. Готовая программа находится в [bin](../bin/README.md), архивы — в [dist](../dist/README.md). Сам выпуск подготавливает [scripts/package-release.ps1](../scripts/package-release.ps1).
