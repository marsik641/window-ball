# Window Ball 1.0.0

Первый выпуск настольного теннисного мяча для Windows.

- Мяч поверх окон: хватай мышью и бросай об края экрана.
- Гравитация, вращение, отскоки и постепенная остановка.
- Размер и упругость на выбор, пауза и режим без гравитации.
- Несколько мониторов, масштабирование DPI и значок в трее.
- Переносимая программа без установки и доступа к сети.

## Скачать и запустить

Распакуйте `WindowBall-v1.0.0-win-portable.zip` в доступную для записи папку и запустите `WindowBall.exe`.

Требуется Windows 10/11 с .NET Framework 4.8. Проверить целостность архива можно по `SHA256SUMS.txt`.

Левая кнопка — схватить и бросить, двойной щелчок — подбросить, правая кнопка — настройки и выход.

Мяч отображается поверх обычных окон; системные защищённые экраны и эксклюзивный полноэкранный режим управляются Windows.
