# История изменений

## 1.0.0 — 2026-10-22

- Теннисный мяч поверх окон Windows с прозрачным фоном.
- Перетаскивание, броски, гравитация, вращение и отскоки от границ монитора.
- Три размера и три уровня упругости, пауза и режим без гравитации.
- Перенос между мониторами, поддержка DPI, возврат мяча через трей.
- Сохранение настроек рядом с программой, один экземпляр приложения.
- Сборка без сторонних пакетов, автоматические проверки и подготовка переносимого архива.
